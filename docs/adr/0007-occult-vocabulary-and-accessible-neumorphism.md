# ADR 0007: Pair precise occult vocabulary with accessible neumorphism

- Status: Accepted
- Date: 2026-09-08

## Context

Anomalous needs a coherent identity without sacrificing searchability,
debuggability, or interface clarity.

## Decision

Platform abstractions use the canonical occult vocabulary in
`docs/nomenclature.md`; each term has one technical meaning and is introduced
with a familiar computing term in external prose. Decorative language does not
replace conventional units, schemas, or errors.

The human interface uses restrained neumorphism. Depth and motion never carry
state alone: contrast, text or icon labels, shape, focus, keyboard operation,
semantic accessibility, and reduced-motion behavior are required.

## Consequences

New abstractions and UI components require terminology and accessibility review.
The result can remain distinctive without becoming obscure or exclusionary.
