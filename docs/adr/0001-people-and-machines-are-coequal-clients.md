# ADR 0001: People and machines are coequal clients

- Status: Accepted
- Date: 2026-09-08

## Context

Interfaces built only for people are brittle to automate. Interfaces built only
for machines can become opaque and unsafe for the people affected by them.

## Decision

Human surfaces, shells, automation, and AI use projections of one typed semantic
system model. They share discovery, previews, sigil checks, policy, progress,
cancellation, results, attribution, and recovery. No client class receives
ambient or hidden authority.

The visual system optimizes beauty and calm for people. The underlying object
tree, schemas, and structured events optimize legibility for machines. Neither
projection is reconstructed unreliably from the other.

## Consequences

Features require semantic and accessibility design in addition to rendering.
AI integrations cannot bypass kernel authority or user and enterprise policy.
The same trace can explain an action to a person and a diagnostic system.
