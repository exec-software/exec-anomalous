# Anomalous native frame assets

Original Anomalous native frame recipes inspired by Antimatter's Clay palette:
neutral charcoal and warm light surfaces, orange focus, and teal secondary
accents. Light is an Anomalous interpretation. No Antimatter glyphs, fonts, or
frame assets are copied.

The original visual study used Antimatter's Clay palette and frame composition
as design references. The public token snapshot is available in
<https://github.com/exec-software/exec-antimatter/tree/master/vendor/displacer>.
It is background design context, not a build dependency or an exact public
reproduction of the historical reference. Native recipes in this repository
are the authoritative source for these generated assets.

## Source and regeneration

Do not edit exported SVGs or the manifest by hand. The authoritative window
controls are the bounded vectors in
`crates/anomalous-desktop-theme/src/assets.rs`. Native composition samples
those same recipes with integer 4 x 4 coverage; SVG exports retain the original
round-cap segments. The coverage approximation is native renderer behavior,
not a promise that a browser's SVG rasterizer returns identical pixels.

From the repository root:

```sh
cargo run -p anomalous-desktop-theme --example export_assets --target x86_64-unknown-linux-gnu
cargo run -p anomalous-desktop-theme --example export_assets --target x86_64-unknown-linux-gnu -- --check
```

`--check` compares every generated byte and rejects missing or extra files.
An optional `--out DIRECTORY` exports to another host directory.

## Scope

`icons/` contains symbolic 24 x 24 SVGs using `currentColor`. The dark, light,
and high-contrast directories contain four frame-state references and a
normal/hover/pressed/inactive/disabled control sheet. `contact-sheet.svg` uses relative
references, so keep the package together when viewing it. The four controls
are minimize, maximize, restore, and close.

Frame references derive colors, metrics, border width, corner radius, and
depth from the compiled theme definition. Floating active and inactive frames
have rounded corners; maximized and tiled references have square corners and
no shadow. Active frames pair the outer focus border with a one-pixel inner
keyline in every theme. Disabled controls include a short baseline mark and do
not acquire a hover or pressed background. Reference text uses the viewer's
sans-serif font. Native text remains
the embedded bitmap font, and the native compositor owns its bounded shadow
implementation and pixel output. These SVG references are not framebuffer
goldens or a runtime package format.

There is no runtime SVG parser, external asset loader, font dependency, or
executable theme code. Native control recipes remain allocation-free and
unsafe-free. Theme and frame state remain available in the canonical semantic
model independently of these pixels.
