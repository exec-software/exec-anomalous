# Welcome to Anomalous

Anomalous is an open-source operating-system research project for human and
machine clients. The current source includes Threshold boot, a Rust kernel,
bounded execution proofs, and an experimental native workspace.

Start with [README.md](README.md) for scope and build instructions, then read
[CONTRIBUTING.md](CONTRIBUTING.md) before changing platform contracts. Historical
measurements and open research questions live in [notebook/](notebook/README.md).

This is pre-alpha software. Use an isolated VM with disposable inputs; general
application support and production security remain unfinished.
